# Store delivery-rate check (user task, about 1 hour)

Purpose: test the belief that South African online stores cap delivery near R100, and see whether stores earn a margin on shipping. Do this before the price ceiling and store commission are fixed.

Pick 10 stores (mix of sizes, some WooCommerce, some Shopify). For each, put a Johannesburg-north item in the cart and read the delivery options at checkout. Then price the same parcel (similar size and weight, same addresses) on the courier's own public website.
